  - (г) стоимость выглядит «125 000» — разделитель тысяч;

  - (ж) «Статус гарантии» — те же слова и разбивка, что бейджи на сайте (Действует/Истекает/Истекла/Без гарантии).

- **Результат:** pass

### Шаг 7 — Сессионный гейт (SC 4) — с диагностикой, НЕ дефект
- **Проверка:** без сессии (выход из системы / приватное окно) прямой GET `/api/devices/export-xlsx` не отдаёт файл — redirect на логин.
- **Результат:** pass
- **Диагностика (наблюдение в ходе приёмки):** пользователь сначала наблюдал скачивание файла в «приватном» окне. Диагноз: в браузере присутствовал ВАЛИДНЫЙ session-cookie — 30-дневный JWT сессии (D-01); Safari в приватном режиме разделяет cookies с основной сессией, поэтому «выход из сессии» приватным окном не эмулируется. Оркестратор проверил гейт живьём на работающем dev-сервере: запрос без cookie → 307 (redirect на логин), запрос с мусорным cookie → 307. Гейт requireSession-first работает корректно; после объяснения пользователь одобрил шаг. **НЕ дефект.**

- **Результат:** pass
