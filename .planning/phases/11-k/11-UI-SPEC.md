# Phase 11 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
> Sources: `11-CONTEXT.md` (D-01..D-08 — ALL locked, used verbatim; стилистика/компонентная структура палитры и точные копи — declared discretion: «Компонентная структура палитры…, стилистика — ui-phase»), `11-RESEARCH.md` (official Base UI Dialog+Autocomplete command-palette recipe of the installed ^1.7.0, Patterns 1–4, Pitfalls 1–9, `/api/search` JSON shape), `REQUIREMENTS.md` (FIND-06; §Out of Scope — cmdk/Radix/новые npm запрещены), approved `10-UI-SPEC.md` / `09-UI-SPEC.md` / `07-UI-SPEC.md` / `02-UI-SPEC.md` (binding design language, dialog recipes, accent discipline, empty-state vocabulary), implemented code (`app/globals.css` tokens, `components/ui/dialog.tsx` — scrim/motion recipe + `data-slot="dialog-content"` probe, `components/ui/combobox.tsx` — `data-highlighted:bg-accent` highlight semantic, `app/(app)/layout.tsx` — app-bar geometry, `app/(app)/nav.tsx`, `app/(app)/devices/search-box.tsx` — input recipe, employee card `[id]/page.tsx` — «В архиве» chip recipe, `lib/ru.ts` plurals, `lib/device-schema.ts` DEVICE_TYPES).

**Phase character:** the most interaction-dense and least visual phase of the milestone. ZERO new tokens, ZERO new colors, ZERO new sizes: the palette is one new surface archetype — a top-aligned modal command palette — assembled entirely from the official Base UI Dialog+Autocomplete recipe dressed in the existing dialog skin (white popover surface, 16px radius, hairline ring, scrim black/30, 200ms fade+zoom). All interaction behavior (hotkey, toggle, inertness, grouping, keyboard, fresh-fetch) is user-locked in D-01..D-07; this contract fixes its visual dressing and copy. The palette finds what the lists find (D-02) — its rows therefore look like the lists' rows: model/ФИО at 16/400, one 14/400 secondary line, mono numbers, the archive chip from the employee card.

## Spacing Scale

Inherited from 02-UI-SPEC unchanged: xs 4 / sm 8 / md 16 / lg 24 / xl 32 / 2xl 48 / 3xl 64. Standing exceptions hold (44px min interactive height `min-h-11`; 12px control padding-x `px-3`, `pt-3`/`gap-3` allowed; `mt-1.5`/`py-2.5`/`px-2.5` forbidden; badge `py-0.5` precedent).

Phase 11 specifics:
- **Palette shell:** top-aligned overlay — `fixed top-[15vh] left-1/2 -translate-x-1/2 z-50 w-full max-w-[calc(100%-2rem)] sm:max-w-xl` (576px content width), `rounded-2xl bg-popover ring-1 ring-foreground/10 shadow-lg p-0`, same `duration-200 ease-out` fade+zoom-in-96 enter/exit as every dialog (apple-design §7). Spotlight-style top placement: the palette is an input-first tool, not a form dialog (documented vh-based exception, mirrors `fixed bottom-4` vh/fixed positioning precedent of phase 10's panel).
- **Input row:** `h-12` (48px), `px-4`, Search icon 16px at `left-4`, text starts at `pl-11` (44px); `border-b border-hairline` separates input from results.
- **Results list:** `max-h-[60vh] overflow-y-auto py-2` (8px top/bottom; 60vh cap keeps the shell on screen — vh exception as above). Group label rows: `px-4 pt-3 pb-1` (12px standing exception + 4px).
- **Result rows:** `min-h-11` (44px touch rule), `px-4 gap-3`, two lines (primary + secondary). Full-width hit area, no nested padding.
- **Empty / error block:** `px-4 py-8` centered, single 14/400 line.
- **CSV row (last item):** `min-h-11 px-4` + `border-t border-hairline` pinned visually as the footer row while remaining the last keyboard stop (D-07).
- **Nav button:** quiet text button in the app-bar right group (mirrors «Выйти»'s register — the compact 48px bar holds `text-sm` text controls, the 44px rule governs primary interactive targets); visible kbd chip `rounded-md border border-hairline px-2 py-0.5 text-sm text-ink-secondary` (badge `py-0.5` precedent), `gap-2` from the Search icon.
- Nav, layout, lists, cards: untouched — the island mounts in `app/(app)/layout.tsx`, zero layout shift.

Exceptions: the two vh-based values (`top-[15vh]`, `max-h-[60vh]`) and the chip's `py-0.5` (badge precedent) — all documented above; everything else on-scale.

Inherited unchanged — exactly 4 sizes, exactly 2 weights (400 + 600; no 500 anywhere):

| Role | Size | Weight | Line Height | Tracking | Tailwind |
|------|------|--------|-------------|----------|----------|
| Label / secondary | 14px | 400 | 1.45 | 0 | `text-sm` |
| Body | 16px | 400 | 1.5 | 0 | `text-base` |
| Heading | 20px | 600 | 1.2 | -0.01em | `text-xl tracking-tight` |
| Display | 28px | 600 | 1.2 | -0.02em | `text-[28px] tracking-[-0.02em]` |

Role assignments for this phase:
- **Heading (20/600): none visible.** The palette renders a `sr-only` `DialogTitle` «Глобальный поиск» (Base UI a11y requirement) — visually the palette is titleless, input-first.
- **Body (16/400):** the palette input text and the primary line of every result row (model / ФИО) — matches list rows and the devices search-box input exactly.
- **Label (14/400):** group labels «Устройства» / «Сотрудники» (`text-ink-secondary`), secondary lines (тип · номер · держатель / отдел), the kbd chip «⌘K», nav button text, empty/error lines, the CSV row, the «В архиве» chip.
- **Display (28/600): unused.**
- **No new sizes, no new weights.** The Base UI `Autocomplete.GroupLabel` and `Autocomplete.Item` receive the Tailwind classes above; `autoHighlight` styling is class-driven (`data-highlighted:` variants), not typography.

## Visual Details

- **Motion:** inherited — palette enters/exits `fade-in-0 + zoom-in-96 → out`, `duration-200 ease-out` along the same path (the `DialogContent` recipe classes, applied to the palette's own top-aligned `DialogPrimitive.Popup`; Base UI sets `data-open`/`data-closed` attrs). `prefers-reduced-motion` collapses it via the existing global media query — nothing to add.
- **Scrim:** `bg-black/30` fade, no blur (the `DialogOverlay` recipe, reused verbatim).
- **Highlight mechanics (library-owned):** `autoHighlight="always"` + `keepHighlight` — the first row is always highlighted, including on open with q='' (D-06 Enter-always-has-a-target); `loopFocus` defaults to true — ↑↓ cycles cyclically through rows and back into the input, per ARIA APG. No hand-rolled keydown state machine anywhere (research Don't-Have-Roll).
- **Escape (Pitfall 5 / A1):** explicit `onKeyDown` Escape → close on the `Autocomplete.Input` from the start (1 deterministic line), so Esc always closes the palette regardless of Autocomplete's own popup semantics; asserted in UAT.
- **Hotkey (D-04, research Pattern 1):** window keydown, `e.code === 'KeyK'` + (`metaKey||ctrlKey`), `!altKey && !shiftKey`, `preventDefault()` (beats Chrome Ctrl+K), `e.repeat` dropped, toggle: open⌘K closes. Branch order: toggle-close FIRST, then the other-dialog probe `document.querySelector('[data-slot="dialog-content"][data-open]')` **excluding the palette's own popup** (palette popup carries `data-command-palette`; the query is `'[data-slot="dialog-content"][data-open]:not([data-command-palette])'`) — Pitfall 4 (⌘K must always be able to close the palette).
- **Fresh state (D-03, Pitfall 8):** on close: `abort()` in-flight fetch, clear `q` and results; the palette popup is NOT `keepMounted` — state dies with the palette. No URL state for the palette itself (only «Показать все» targets carry ?q=).
- **Fetch (research Pattern 3):** instant fetch on open (q=''), 300ms debounce per keystroke, AbortController cancels the previous request; `content-type` guard before `res.json()` — a session-expiry 307→/login renders as empty, not a crash (Pitfall 3); network failure renders the error line (Copywriting).
- **Navigation (Pitfall 9):** Enter/click → `router.push(/devices/{id} | /employees/{id})` AND `setOpen(false)` in the same handler; optional `usePathname()` effect closes on any pathname change (covers Back while open). The CSV row is a native `<a href="/api/devices/export">` (download semantics — NOT router.push), and closing the palette on its click is part of the same handler.
- **Smoke needles** (no component test runner; UAT via Playwright MCP, phase-7/10 pattern): `data-command-palette` (popup — inertness probe exclusion + UAT), `data-palette-input`, `data-palette-empty`, `data-palette-error`. Rows are reachable via `role="option"` + visible text; groups via `role="group"` + accessible name.
