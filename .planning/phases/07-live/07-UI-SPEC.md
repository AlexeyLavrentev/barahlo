# Phase 7 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
> Sources: `07-CONTEXT.md` (D-01..D-10 — ALL locked by user, used verbatim; nothing re-asked), `07-RESEARCH.md` (hook API Pattern 2, URL Pattern 3, empty-state pattern, Pitfalls 1–8), `REQUIREMENTS.md` (FIND-05; §Out of Scope — no new npm deps, no fuzzy search), approved `05-UI-SPEC.md` (the binding design language — this phase EXTENDS it: tokens, typography, spacing, accent discipline unchanged; the `/employees` page and the search-box recipe are the extension points), `02-UI-SPEC.md` (visual language base), implemented code (`app/(app)/devices/search-box.tsx` — the reconciliation source, `app/(app)/employees/page.tsx`, `app/(app)/devices/page.tsx` empty state, `app/globals.css` tokens, `lib/ru.ts`), skill `apple-design`.

**Phase character:** this is the SECOND installation of an already-shipped mechanism, not a new design. ## Visual Details (inherited + new)

- Radii/motion/shadows: inherited — cards 16px (`rounded-2xl`), controls 8px (`rounded-lg`), `shadow-sm` on cards; every interactive element `active:scale-[0.97] duration-100 ease-out`; color-only transitions `duration-150 ease-out` (segmented links, rows).
- **Search update mechanics (D-06, D-07; verbatim device behavior):** 300 ms debounce → `router.replace(buildEmployeesQuery({…target, q}), { scroll: false })` inside `startTransition`. **No spinner, no skeleton flash per keystroke, no input blocking** — the transition keeps the current list mounted until the server render swaps in (D-06: «Спиннер добавится по ощущению тормозов на UAT» — none now). The controlled input keeps focus and value across the swap. The existing `loading.tsx` remains the fallback for hard navigations only.
- **Search field anatomy** (byte-parity with `DeviceSearchBox`): controlled `input` **outside any `<form>`** (React 19 reset landmine, 4886f6a), `type="search"` (native clear affordance), `maxLength={100}` (mirrors the server cap), leading lucide `Search` 16px `text-ink-secondary` absolutely positioned `left-3 top-1/2 -translate-y-1/2`, input classes `h-10 w-full rounded-lg border border-hairline bg-white px-3 pl-9 text-base text-ink outline-none transition-colors placeholder:text-ink-secondary focus-visible:border-ring focus-visible:ring-3 focus-visible:ring-ring/50`.
- **Reconciliation contract (the load-bearing part — G-5-1/G-5-2):** local edits always win over the URL; the URL is adopted into the input only when the input is clean (Back/Forward, «Сбросить поиск»); the island's own pushes are recognized as echoes via `inFlight` (cap 4) and absorbed without clobbering fresher keystrokes; a trailing space mid-composition is never rewritten away. This logic moves into the shared hook **verbatim** (D-07) — the hook is not redesigned.
- **Shared hook contract (research Pattern 2; the interaction API Phase 11 will consume):**

```ts
// lib/use-search-param.ts (name/path = default, see Defaults #7)
useDebouncedSearchQuery<Q extends { q: string }>(args: {
  q: string                    // server echo prop (validated by query-params.ts)
  target: Omit<Q, 'q'>         // builder data WITHOUT q (employees: { filter })
  buildQuery: (f: Q) => string // STABLE module ref imported by the island — never a prop (not serializable across RSC)
}): { value: string; setValue: (v: string) => void; commitNow: () => void }
// Effect deps semantically = today's [value, q, current, router].
// Enter → commitNow (drops the pending timer, pushes now). 300 ms timer otherwise.
```

- **URL is the only search state (D-05):** `?q=` lives beside `?filter=`/`?page=`; the ONE builder (`employees/query-params.ts`, by the `devices/query-params.ts` pattern) builds every link. New q push **omits `page`** → server defaults to page 1 (reset by omission); hostile `?q=…&page=999` clamps server-side; q is trimmed and capped at 100 server-side. Segmented links and pagination links carry q in the full query string — a bare `?page=2` or `?filter=archive` would drop the search (standing Pitfall-3/6 rule).
