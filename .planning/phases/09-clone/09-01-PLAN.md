Клон устройства (REG-06): кнопка «Дублировать» на карточке открывает диалог количества (1..100); одна транзакция создаёт N копий — наследование закупочного блока и конфигурации типа (D-04), чистые серийник/заметки/фото/история/владелец (D-05), ноль movement-событий (D-06), редактируемая подсказка инвентарника «следующий по шаблону» (D-02). Purpose: закупка партии одинаковой техники — один диалог вместо N ручных созданий; копии «на складе» и готовы к выдаче (SC 1–4).

Shape note (no-tracer rationale): слои фазы строго последовательны — checkpoint:decision → миграция (иначе INSERT NULL-серийника невозможен) → query/lib ядро (иначе экшену нечего вызывать) → UI. Механика каждого слоя байт-копируется с probe-верифицированных in-repo аналогов (RESEARCH Patterns 1–5, PATTERNS-карта 13/13 аналогов) — вертикальный трассировочный срез не дал бы новой архитектурной информации, только удвоил бы работу над диалогом.
