## Spacing Scale

Inherited from 02-UI-SPEC unchanged: xs 4 / sm 8 / md 16 / lg 24 / xl 32 / 2xl 48 / 3xl 64. Standing exceptions hold (44px min interactive height `min-h-11`; 48px header `h-12`; 12px control padding-x `px-3`; `mt-1.5`/`py-2.5`/`px-2.5` forbidden; 12px `mt-3`/`gap-3` allowed as before).

Phase 6 specifics (all inside the existing `max-w-3xl` column):
- **Page head:** «Дашборд» title, «Всего: …» subtitle at `mt-1` (4px).
- **Tiles zone:** `mt-6` beneath the head (the devices filter-bar rhythm); one grid `grid grid-cols-2 gap-3 sm:grid-cols-4` — 8 tiles, types then statuses; 12px `gap-3` (allowed half-step). Mobile 2×4, sm+ 4×2. Tile padding `p-4` (16px); label under count at `mt-1`.

- **Card rows (counters, top-5, feed):** the standing list-row recipe `min-h-11 px-4 py-2`, `divide-y divide-hairline`. Sub-header row inside the warranty card: `px-4 py-2`.
- **Feed row internals:** line 2 at `mt-1` under line 1; `gap-2` (8px) between pill/serial/date and their neighbours.

## Typography

Inherited unchanged — exactly 4 sizes, exactly 2 weights (400 + 600; no 500 anywhere):

| Role | Size | Weight | Line Height | Tracking | Tailwind |
|------|------|--------|-------------|----------|----------|
| Label / secondary | 14px | 400 | 1.45 | 0 | `text-sm` |
| Body | 16px | 400 | 1.5 | 0 | `text-base` |
| Heading | 20px | 600 | 1.2 | -0.01em | `text-xl tracking-tight` |
| Display | 28px | 600 | 1.2 | -0.02em | `text-[28px] tracking-[-0.02em]` |

Role assignments for this phase:
- **Display (28/600):** tile counts — the dashboard's summary numerals (the role's page-title usage stays on device/employee cards; here 28/600 is the count, ink, `leading-[1.2]`).
- **Heading (20/600):** page title «Дашборд», block headers «Гарантия» and «Последние перемещения».
- **Body (16/400):** device model names in top-5 rows and feed rows (the row-line-1 role everywhere else in the app).
- **Label (14/400):** «Всего: …» subtitle, tile labels, warranty counter rows, sub-header text is the exception below, top-5 line 2 («гар. до …»), feed line 2 (route, names, «склад», date), serial numbers (`font-mono text-sm`), empty-state copy inside cards, event pills.
- **14/600 (the allowed third weight application, phase-3 «in-dialog group header» recipe):** the warranty card's inner sub-header «Ближайшие сроки» (`text-sm font-semibold text-ink`) — a mini-header separating counters from the top-5 list, same semantics as phase 4's timeline event labels.
- **No new sizes, no new weights.** Counts are never rendered at a 5th size; «Всего: N» stays 14/400 secondary (D-03 makes it a quiet headline, not a hero).
- **Mono:** серийник renders `font-mono text-sm` in feed line 1 — the established identifier treatment; never on model names, dates, or counts.
- **WarrantyDate inherits the local text role and changes ONLY the color** — in the top-5 list it renders 14/400 (the component's list-context behavior via `variant="card"`; the ` · гар. до …` list-variant prefix belongs to registry rows, not this block — 06-RESEARCH Pattern 3).

## Visual Details (inherited + new)

- Radii/motion/shadows: inherited — cards/tiles 16px (`rounded-2xl`), controls 8px (none new here), pills full; `shadow-sm` on cards and tiles; every link-surface (tile, counter row, top-5 row) gets `active:scale-[0.97] duration-100 ease-out`; hover fill `bg-page` fade 150ms.
- **NEW — the text-link style (feed-owned, app-wide precedent):** linked text (model names, employee names) = the local size/weight + `text-accent`; hover adds `underline underline-offset-2`; no visited state, no bolding. Inside the device anchor, the serial span keeps `font-mono text-ink-secondary` (one target, two-color content — Apple Mail's blue-name/gray-preview pattern). Plain text in the same rows («склад», «→», dates, pill) never takes the link style — the color IS the affordance, which matters on touch where hover does not exist.
- **Tile:** `<Link>` styled as a quiet card — `rounded-2xl bg-white p-4 shadow-sm ring-1 ring-hairline`, `hover:bg-page`, `active:scale-[0.97]`, `focus-visible:ring-2 ring-accent/30`. Content: count (28/600 ink) over label (14/400 secondary, `truncate`, `mt-1`). No chevron, no icon, no pill — the number is the interface.
- **Event pill:** exact phase-3/4 status-pill recipe `rounded-full bg-black/5 px-2 py-1 text-sm text-ink-secondary`, label from `movementEventLabel`. «Списание» alone takes `bg-destructive/10 text-destructive`. The pill is `shrink-0` in feed line 1.
- **Feed row (segmented links — NEVER one anchor):** row container `min-h-11 px-4 py-2 hover:bg-page` with NO href of its own (nested anchors are invalid HTML — research Pitfall 4). Line 1: pill (`shrink-0`) + `<Link href="/devices/[id]">` (min-w-0: model span `truncate` 16/400 accent, serial span `font-mono text-sm text-ink-secondary shrink-0`) + full line in a `title` attribute. Line 2 (`mt-1`, `flex items-center justify-between gap-2`): route span (14/400 secondary, `truncate`, contains the employee `<Link>`s) + date span (14/400 secondary, `shrink-0`, `occurredAtFormat` → «дд.мм.гггг, чч:мм»).
- **Feed route rendering per event type** (phase-4 timeline vocabulary, names now links, «склад» for the null person slot in custody moves — Defaults #6):

| eventType | Pill | Route line (line 2 left span) |
|-----------|------|-------------------------------|
| `received` | Поступление | *(no route — date alone, timeline «—» precedent)* |
| `assigned` | Выдача | склад → {кому} |
| `transferred` | Передача | {от кого} → {кому} |
| `returned` | Возврат | {от кого} → склад |
| `to_repair` | В ремонт | от {держателя, если был} |
| `from_repair` | Из ремонта | *(no route)* |
| `disposed` | Списание | *(no route)* |

- **Warranty counter row:** `<Link>` row, `min-h-11 px-4 py-2 hover:bg-page`, text «{условие}: {N}» (14/400 ink) + `chevron-right` right. Neutral text — no state color (see Color).
- **Top-5 row:** `<Link>` row to `/devices/[id]`, two lines, `min-h-11 px-4 py-2 hover:bg-page` + `title`. Line 1: модель (16/400 ink, `truncate`) + `chevron-right`. Line 2: «гар. до » (14/400 secondary) + `<WarrantyDate value today variant="card" />` (inherits 14/400 here, renders warn orange).
- **Empty rows:** warranty empty and feed empty render as quiet in-card rows (see Copy) — no illustration, no icon, no CTA (the counters/linked blocks above them ARE the next step).
- **`metadata`:** `export const metadata = { title: 'Дашборд' }` on the page — the tab must not keep the root default «Учёт техники» (research Pitfall 9).
