## Spacing Scale

Inherited from 02-UI-SPEC unchanged: xs 4 / sm 8 / md 16 / lg 24 / xl 32 / 2xl 48 / 3xl 64. Standing exceptions hold (44px min interactive height `min-h-11`; 48px header `h-12`; 12px control padding-x `px-3`; `mt-1.5`/`py-2.5`/`px-2.5` forbidden; 12px `mt-3`/`gap-3` allowed as before).

Phase 5 specifics:
- **Filter bar:** replaces the current `mt-6` type-filter wrapper — `mt-6 flex flex-wrap items-center gap-2` (D-12: one visible bar, no popover). Every control in the bar is **`h-10`** to read as one line of equal-height controls (matches the existing type-filter trigger override).
- **Search field:** `flex-1 min-w-48` (192px minimum, absorbs slack); leading icon inset `left-3` (12px), 16px icon, text starts at `pl-9` (36px — on the 4px grid, not a forbidden half-step).
- **Selects:** `w-full sm:w-40` (тип/статус/отдел); гарантия `sm:w-48` («Истекает ≤ 60 дней» must not truncate in the trigger). Existing type-filter trigger narrows `sm:w-48` → `sm:w-40` as part of the bar composition (one class).
- **RAM chip:** `h-10 px-3 rounded-full` — pill, same height as neighbours.
- **CSV button:** secondary button, size override `h-10` to match the bar; sits at the row end (`ml-auto`).
- **Empty-state reset button:** `mt-4` beneath the hint inside the normal empty-state card.
- `flex-wrap` wrapping to a second line at the `max-w-3xl` column is **correct behavior, not a bug** (see Defaults #1 — D-12's «одной строкой» = one visible bar, not one physical line at every width).

|-------|------------------------------------------|-------|----------|
| `ok` | warranty date > today + 60 days | `#34C759` | `text-warranty-ok` |

Explicitly NOT accent and NOT colored: the RAM chip's pressed state (solid ink `bg-ink text-white` — the established neutral-strong state of «Вернуть всю технику»/archive confirms, not accent), the CSV button (secondary neutral), select triggers (secondary text), the «Найдено: …» subtitle, warranty colors on anything but the date text (no backgrounds, no pills, no dots).

## Visual Details (inherited + new)

- Radii/motion/shadows: inherited — cards 16px, controls 8px (`rounded-lg`), pills/chips full; `shadow-sm` on cards; every button/row `active:scale-[0.97] duration-100 ease-out`; select popovers opacity+scale 150ms (existing).
- **Filter bar controls** are buttons/links — the global press rule applies to the chip and CSV button; Selects animate their popovers only.
- **Search update mechanics (D-01, research Pattern 3):** 300 ms debounce → `router.replace(href, { scroll: false })` inside `startTransition`. **No spinner, no skeleton flash per keystroke:** the transition keeps the current list mounted until the server render (0.9 ms measured) swaps in; the existing `loading.tsx` skeleton remains the fallback for hard navigations (first load, back/forward) only. The controlled input keeps focus and its value across the swap.
- **Chip states:** inactive = `bg-black/5 text-ink-secondary`, hover → `text-ink`; active (pressed) = `bg-ink text-white`. `aria-pressed` carries the state to AT; the fill carries it visually — no checkmark, no color.
- **WarrantyDate** is a colored text span — the entire «гар. до {дата}» segment takes the state color in list contexts (it reads as one unit); on the device card only the date value is colored beneath the existing «Гарантия до» label.
