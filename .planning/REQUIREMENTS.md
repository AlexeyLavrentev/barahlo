# Requirements: Barahlo — учёт корпоративной техники

**Defined:** 2026-09-29
**Core Value:** Мгновенный точный ответ: где находится конкретная единица техники, кто ею пользуется и какая у неё конфигурация — за секунды, поиском или фильтром.

## v1.3 Requirements

Требования вехи v1.3 «Удобство и выгрузка». Каждая маппится в фазу дорожной карты.

### Экспорт

- [ ] **EXP-02**: Руководитель может скачать ведомость устройств в XLSX: те же 20 колонок и тот же состав строк, что CSV-ведомость (EXP-01), те же поверхности экспорта; типизированные ячейки — числа числами (Excel сам рендерит «21,5» в RU-локали), серийники/инвентарники строками без научной записи, даты настоящими Excel-датами

### Фото

- [ ] **PHOTO-01**: Руководитель может рассмотреть фото устройства: в существующем лайтбоксе карточки фото открывается крупно, зум (клик/колесо/пинч) и сброс работают; удаление фото и горячие клавиши карточки не ломаются

- **RPT-01**: Сводка для руководства: агрегаты по типам/отделам + гарантийный прогноз, печатная страница
- **MOB-01**: Мобильная полировка ключевых поверхностей

## Out of Scope

| Feature | Reason |
|---------|--------|
| Email/push-напоминания о гарантии | SMTP+cron ради одного ежедневного пользователя; блок гарантии дашборда уже покрывает |
| Встроенный QR-сканер в браузере | getUserMedia требует HTTPS — на внутреннем http заблокирован; камера телефона открывает QR сама |
| Конструктор отчётов | Конфигурируемость убивает одиночный инструмент; фиксированные сводки + XLSX достаточно |
| Амортизация / бухучётная стоимость | Домен бухгалтерии; XLSX с ценами отдаёт сырьё |
| Комплекты (kits) | Bulk-выдача закрывает за 3 чекбокса |
| Планируемая дата возврата | Рябь по replay-зоне (сильнейшая регрессия v1.2) ради слабого сигнала |
| Роли / самообслуживание | Стабильные решения проекта (один аккаунт) |
