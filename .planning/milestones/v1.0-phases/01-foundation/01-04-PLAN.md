## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| LAN → контейнер :3000 | контейнер публичен всей офисной сети; периметр авторизации обязан работать внутри образа |
| хост сервера → том ./data | bind-mount на хостовую ФС; права и владение — часть границы |
| сборка образа → реестр npm | supply-chain: зависимости попадают в образ |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
