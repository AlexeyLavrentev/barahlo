<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| unauthenticated request → /api/devices/export | the perimeter boundary — bulk data behind it |
| operator-entered device fields → CSV cells → Excel formulas | the export is a file-output injection sink (CWE-1236) |
| URL searchParams → export filters | same untrusted-param path as the page |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-09 | Information Disclosure | /api/devices/export without a session | high | mitigate | two existing layers, both mandatory in the route: proxy.ts default-deny matcher already covers api/*, and requireSession() is the route's FIRST statement (attachments-route precedent); smoke at end-of-phase asserts 307-to-login without a cookie |
| T-05-10 | Tampering / Elevation (on the analyst's machine) | CSV formula injection, CWE-1236 | high | mitigate | tab-prefix guard in the lib/csv.ts escaper for cells starting with = + - @ TAB CR (OWASP-recommended), proven by the Task 2 negative matrix; every cell passes through esc() — no raw join path exists |
| T-05-11 | Tampering (MIME confusion / sniffing) | downloaded file handling | low | mitigate | hardcoded Content-Type text/csv; charset=utf-8 (never echoed from input), X-Content-Type-Options: nosniff, attachment disposition, no-store |
| T-05-12 | Tampering (SQL via filter params) | export parse path | high | mitigate | the SAME zod/enum-degrading parser as the page and bound-parameter drizzle predicates — no new SQL surface |
| T-05-SC | Tampering | npm installs | none | accept | zero new packages — the CSV writer is hand-rolled by design (prohibition above); Package Legitimacy Audit: none |
